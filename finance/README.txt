Финансы — личное PWA для учёта доходов и расходов

Данные хранятся только на телефоне (localStorage).
Интернет нужен один раз, чтобы открыть сайт и поставить иконку.

Как выложить бесплатно (Cloudflare Pages — самый простой вариант)

1. Зайдите на https://pages.cloudflare.com и войдите (можно через Google/GitHub).
2. Create a project → Upload assets.
3. Загрузите всю папку finance-pwa целиком (index.html должен быть в корне загрузки).
4. Получите ссылку вида https://имя.pages.dev
5. На iPhone откройте ссылку именно в Safari.
6. Кнопка «Поделиться» → «На экран Домой».

Другие бесплатные варианты: Netlify Drop (https://app.netlify.com/drop) и GitHub Pages.

Как пользоваться
- «+ Операция» — доход или расход
- Нажмите на запись, чтобы изменить или удалить
- В настройках можно сменить валюту и скачать JSON-копию

Важно
Если очистить данные Safari / сайт, записи пропадут.
Периодически делайте «Скачать копию JSON» в настройках.
